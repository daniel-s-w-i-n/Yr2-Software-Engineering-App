### Project Overview

**ECommute** aims to enhance sustainability practices in urban commuting by leveraging data through machine learning algorithms. Our focus is to reduce carbon emissions by optimizing travel routes and promoting carpooling among employees using a user-friendly web application.

---

### Project Objectives
- **Develop Solutions**: Use machine learning to optimize urban commuting routes to minimize carbon emissions.
- **Promote Carpooling**: Implement features to encourage carpooling, reducing the number of vehicles and emissions.
- **User-Friendly Interface**: Create an intuitive web application that allows easy commute planning and real-time carbon footprint tracking.
- **Stakeholder Engagement**: Regularly refine the application based on feedback from users and stakeholders to enhance effectiveness.
- **Scalable Deployment**: Ensure the platform can expand to accommodate more users and adapt to different urban environments.


---

### Technologies Used
- **Milvus Vector Databases:** For efficient similarity search and vector indexing of commuting data.
- **React.js:** To build a dynamic and responsive user interface.
- **Flask & Spring Boot (Java):** Backend development for API management and server-side logic.
- **PostgreSQL (Supabase):** For secure and scalable database management.
